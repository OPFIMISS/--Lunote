## 2. 已实现能力（真实运行验证）

- **自动发现**：UDP 组播 239.255.77.77 + 有限广播 + 子网定向广播；LUNOTE1 协议（版本字段、错误包忽略、seq 去重、重启替换、同名区分、改名更新、离线超时、多网卡逐接口、后台节流）。
- **持久身份**：Ed25519 密钥 + 自签名证书（rcgen），指纹 = SHA-256(证书)；instance_id 每次启动随机。
- **信任管理**：TOFU 记录 + 用户按钮确认（指纹短码展示）；身份变化 → 警告 + 降级；未信任设备可发文字/链接，文件自动拒绝。
- **TLS 1.3 会话**：rustls(ring) 仅 1.3；应用层签名挑战（防重放）；双向认证；心跳与空闲超时；读/写独立任务（杜绝 select 取消半途 IO 的流损坏）。
- **消息**：文字、链接双向传输；自动识别 URL。
- **文件/文件夹传输**：256 KiB 流式分块（不整文件载入内存）、16 块滑动窗口、双端增量 SHA-256 校验、临时文件 + 原子改名、文件名/路径净化（防穿越）、同名自动加序号、剩余空间检查、发送前信任门禁、接收逐次确认。
- **取消/失败/续传**：任一侧取消（删除 .part）；连接断开保留 .part 并标记可续传；重连后 resume_token + 部分哈希校验接续；不一致则从头重传。
- **加密记录**：SQLite + 逐记录 AES-256-GCM（随机 nonce）；密钥独立文件；数据文件无明文（测试断言）。
- **导出/导入**：Argon2id（64MiB/t=3/p=1）+ AES-256-GCM 信封；导入校验完整性 + 按 UUID 去重；错误密码/篡改均拒绝。
- **UI**：全新 Flutter 界面（深色月笺主题、自定义无边框标题栏、弹簧交互、拖放发送、托盘、后台节流开关）；设备/对话/传输/设置四区；所有数据来自核心事件。
- **核心独立性**：lunote-cli 无头运行 + 控制文件驱动 + 事件文件输出；FFI 桥（JSON 命令）供 UI 调用。

## 5. 如实说明的安全边界（详见 `docs\安全模型.md`）

- 首次信任为 TOFU + 按钮确认：局域网内抢先冒充的全新设备若用户不核对指纹，可能被信任（界面展示指纹短码，文档建议核对）。
- 发现信标明文（含设备名，无内容）；攻击者可伪造信标造成假在线/离线（DoS），不能读取会话内容。
- 密钥文件权限 0600（Unix）；Windows 依赖目录 ACL；DPAPI 包裹为后续改进。
- 记录库元数据（会话名、时间戳）不加密；内容加密。
- 导出文件自包含加密容器；密码丢失 = 不可恢复。

## 6. 已知限制

- 同一会话同一时刻一个发送方向任务（多文件排队），双向互不阻塞。
- 子网定向广播依赖 if-addrs 提供的广播地址；个别多网卡环境可能覆盖不全（组播+有限广播已覆盖常见场景）。
- 文件接收必须先由用户选择保存目录（逐次确认，符合安全设计）。
- 断点续传依赖接收端 `.part` 与元数据；手动删除将从头传输。
- 大文件（>4GiB）未做专项测试（协议为 u64 偏移，理论支持；待大文件回归）。
- Android 后台：遵守系统规则，退后台由系统调度；活跃传输期间建议保持前台。
