# 月笺 Lunote 构建说明

> 所有工具链位于 `D:\Lunote 2\.toolchains\`（工作区内，不占系统盘、不映射盘符）。

## 2. 核心（Rust）

```powershell
$env:CARGO_HOME = 'D:\Lunote 2\.toolchains\cargo-home'
$env:CARGO_TARGET_DIR = 'D:\Lunote 2\.toolchains\rust-target'

# 单元 + 集成测试（含真实 socket 本机多实例）
cargo test --manifest-path moonletter\Cargo.toml --workspace --no-fail-fast

# 发布构建（Windows）
cargo build --manifest-path moonletter\Cargo.toml -p lunote-cli --release
cargo build --manifest-path moonletter\Cargo.toml -p lunote-bridge --release
```

产物：`lunote-cli.exe`、`lunote_bridge.dll`。

## 3. Android（APK）

前置：NDK 27.1 已存在；安装 Rust 交叉目标与 cargo-ndk：

```powershell
rustup target add aarch64-linux-android armv7-linux-androideabi x86_64-linux-android
cargo install cargo-ndk
```

编译核心为 .so 并放入应用：

```powershell
cd moonletter\crates\lunote-bridge
cargo ndk -t arm64-v8a -t armeabi-v7a -t x86_64 -o ../../app/android/app/src/main/jniLibs build --release
```

然后：

```powershell
cd moonletter\app
flutter build apk --release
```

产物：`app\build\app\outputs\flutter-apk\app-release.apk`。
（需要 Android licenses 接受；首次构建 Gradle 会下载依赖。）

## 4. Windows 桌面

```powershell
cd moonletter\app
flutter build windows --release
```

产物：`app\build\windows\x64\runner\Release\lunote_app.exe`；
把 `lunote_bridge.dll` 复制到同目录（构建脚本自动处理）。

## 5. Linux

- 本机（Windows）无法直接构建 Flutter Linux 桌面二进制（需要 Linux 工具链），
  如实标注：Linux 构建配置已随 `app/linux/` 提供；
- 提供 GitHub Actions 工作流在 ubuntu 上构建 Linux 与 Windows/Android 产物
  （见 `.github/workflows/build.yml`）；
- Rust 核心可交叉编译 Linux CLI（x86_64-unknown-linux-gnu，需 zig 或
  Linux 工具链），验证后补充。

moonletter\app\build\windows\x64\runner\Release\lunote_app.exe

## 6.1 一键重建（Windows 桌面 + Android APK）

```powershell
powershell -ExecutionPolicy Bypass -File moonletter\tools\build_all.ps1
```

依次执行：Windows 核心 `lunote_bridge.dll` → `flutter build windows` →
cargo ndk 三架构 `.so` → `flutter build apk --release` →
发布产物统一输出到 `moonletter\dist\`（`月笺\` 完整目录 + `月笺.apk`），
日志写入 `moonletter\build_all.log`。

> 产物以 `dist\` 为准；`app\build\` 下的历史构建物可删除（会重新生成）。
> ⚠️ `tools\build_all.ps1` 必须为 **UTF-8 带 BOM**（PowerShell 5.1 按 GBK 读无 BOM
> 文件会把中文路径“月笺”变成乱码目录 `鏈堢`）。

## 6.2 磁盘清理（2026-08-17 已执行）

- 已删除废弃旧项目 `D:\Lunote 2\lunote`（约 16.7GB）；
- 可安全再删（Flutter 会自动重建）：`app\.dart_tool`、`app\windows\flutter\ephemeral`、
  `app\build\` 中间产物（保留 `x64\runner\Release` 与 `outputs\flutter-apk`）；

  `<flutter>\packages\flutter_tools\templates\app\windows.tmpl\flutter\` 恢复）；
- 系统 Temp、npm/pip 缓存已清；`.toolchains\` 下的 verify/smoke/listen 临时目录与
  各类 *.log 已清。
- ⚠️ `tools\build_all.ps1` 必须为 UTF-8 带 BOM（Windows PowerShell 5.1 按 GBK 读无 BOM
  文件会把中文路径/字符串解析坏）。
