## 已接通

- 主对话文字/链接：可信设备的加密本地发送队列、重启恢复、自动重试、接收去重、持久化 ACK 与待送达/已送达状态。
- 删除本地消息时保留接收去重标记，防止未确认的旧消息重发后恢复已删除内容。
- 双方独立临时文字对话：命名、不复制主对话历史、仅本机删除、双方删除及离线删除补发、删除 tombstone、加密备份中的会话元数据。
- 消息全文操作：全文选择、复制全文、删除、批量选择；手机文本选择菜单中提供更多操作入口。

## 跨平台互通复现

先在项目根目录运行 `python tests/android_interop_host.py`，再在 app 目录运行：

```powershell
flutter test integration_test/android_interop_test.dart -d emulator-5554 --no-pub --dart-define=LUNOTE_INTEROP_HOST=<Windows局域网IP>
```

测试使用独立临时数据，Windows端监听45889，Android端监听45890。Android测试通过和Windows端PASS都出现才视为双端完成；发送完成记录须从持久化历史读取，不仅检查活动传输列表。

## 产品边界

- 没有服务器：发送方退出期间无法送达，队列在发送方再次上线后重试。已送达表示接收端保存成功，不等于已读。
- 新可靠消息协议需要双方升级；旧版本不能确认新消息，发送方不会伪造已送达状态。
- 笔记同步设备在每台设备上首次授权一次，之后持续自动同步，不要求每次选设备。未选定的可信设备不会接收笔记。
- 笔记密码不会同步明文，而是同步额外加密后的内容。首次在新设备解锁必须输入笔记密码；可另行启用该设备的系统认证。
- 普通本地记录密钥仍受应用私有目录/系统权限保护；不承诺抵抗管理员、root 或已被控制的系统。
